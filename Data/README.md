# 📊 Sales Data Analysis Project

## 📌 Project Overview
This project analyzes sales data using Python, Pandas, and Power BI to identify sales trends, top-performing products, and regional performance.

The main objective is to convert raw sales data into meaningful business insights that help in better decision-making.

## 🎯 Objectives
- Analyze overall sales performance.
- Identify monthly sales trends.
- Compare region-wise sales.
- Find top-performing products.
- Analyze category-wise sales.
- Build an interactive sales dashboard.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- Streamlit
- Plotly
- Microsoft Power BI

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/parmod-001/Sales-Data-Analysis.git
```

### 2. Open the Project Folder

```bash
cd Sales-Data-Analysis
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Streamlit Dashboard

```bash
python -m streamlit run app.py
```

The dashboard will open in your browser.
